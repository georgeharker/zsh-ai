# zsh-ai

OpenAI-compatible LLM integration for zsh: four keybind-driven
workflows — ask for shell commands, modify what you've typed, ask
freeform questions, and fill-in-the-middle at the cursor — against any
OpenAI-compatible endpoint you've already brought up (llama.cpp,
ollama, LM Studio, vLLM, OpenRouter, …).
